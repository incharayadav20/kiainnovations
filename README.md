# KIA Innovations website

A responsive, static one-page website starter for KIA Innovations.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling (separate stylesheet)
- `script.js` — mobile navigation and current year
- `assets/kia-logo.svg` — editable SVG logo concept

## Before going live
1. Confirm that `kiainnovation@gmail.com` is your active business inbox and test the contact button.
2. Replace the illustrative portfolio concepts with genuine project screenshots and descriptions you have permission to publish.
3. Add your actual contact/social links.
4. Test all sections on desktop and mobile.

## Preview locally
Extract the ZIP and open `index.html` in a browser.

## Free static hosting with GitHub Pages
1. Create a GitHub account and a new repository.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section.

This is a static website. PHP/MySQL applications need a PHP-capable host and database.
Google Fonts are loaded from the internet; system font fallbacks are included.
